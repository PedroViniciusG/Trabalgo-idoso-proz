# Coração Seguro — versão HTML/CSS/JavaScript

Projeto didático baseado em um protótipo mobile desenvolvido no Figma.

## Estrutura

- `index.html` — tela inicial + apresentação do projeto
- `analise.html` — tela para colar uma mensagem
- `resultado.html` — resultado simulado da análise
- `verificar.html` — checklist de comportamento
- `ajuda.html` — central de ajuda
- `css/style.css` — estilos compartilhados
- `js/script.js` — interações em JavaScript
- `assets/` — imagens do projeto

## Como executar

Abra `index.html` no navegador.

Para uma experiência melhor no VS Code, use a extensão **Live Server**.

## Ideias de atividades para os alunos

1. Alterar cores e tipografia no `:root` do CSS.
2. Mudar textos das histórias comuns de golpe.
3. Adicionar uma nova pergunta em `verificar.html`.
4. Criar uma sexta tela chamada `configuracoes.html`.
5. Salvar o nome do contato de confiança usando `localStorage`.
6. Alterar o JavaScript para calcular uma pontuação de risco.
7. Depois, transformar as telas em componentes React/React Native.

## Observação didática

Os nomes de `id`, `class`, funções e arquivos foram escritos de forma explícita para facilitar a leitura por alunos iniciantes.
